# ScoreboardHelper
Provides a few extra functions to use Minecraft Scoreboard more easily.

Modrinth: https://modrinth.com/mod/scoreboard-helper-port

| 1.21.5     | 49                                       |
| 1.21.8     | 2c                                       |
| 1.21.10    | 6f                                       |
| 1.21.11    | 3e                                       |
